# Company lead files

GlowUP company prospects (salons you want to sell the OS to) are **not** written to this folder automatically.

## Where they live

1. **This browser** — `localStorage` key `glowup_company_leads_v1` on the machine/browser you used when you clicked Add to list. Open **Platform** (`/dashboard/platform`) → **Your list**.
2. **A file you can reopen** — on Platform, click **Download backup (JSON)**. Windows saves it to your Downloads folder as `glowup-company-leads-YYYY-MM-DD.json`. Pull it up later with **Import backup** on the same page (any browser).
3. **Meta ads only** — **Export CSV for Meta lookalikes** downloads `glowup-lookalike-YYYY-MM-DD.csv` to Downloads. That file is for Ads Manager, not a full restore.

Clearing site data, switching browsers, or using a different computer wipes the list unless you imported a JSON backup.

You can also drop a downloaded `.json` into this `leads/` folder yourself so it sits next to the repo.
